银行家算法说明

银行家算法是一种死锁避免算法，由艾兹格·迪杰斯特拉提出。该算法以银行借贷系统的分配策略为基础，确保系统在分配资源时不会进入不安全状态。

算法原理

银行家算法通过预先分配资源，确保系统始终处于安全状态。安全状态是指存在一个进程执行序列，使得每个进程都能获得所需的资源，完成任务，释放资源，然后使其他进程也能完成。

算法步骤

  1. 检查请求是否超过声明的最大需求
  2. 检查请求是否超过可用资源
  3. 尝试分配资源，并检查系统是否仍处于安全状态
  4. 如果安全，则分配资源；否则，拒绝请求

数据结构

  • Available: 可用资源向量
  • Max: 最大需求矩阵
  • Allocation: 已分配资源矩阵
  • Need: 还需资源矩阵 (Max - Allocation)

安全性算法

安全性算法用于确定系统是否处于安全状态：

  1. 初始化 Work = Available，Finish[i] = false
  2. 查找满足条件的进程 i：Finish[i] = false 且 Need[i] ≤ Work
  3. 如果找到，则 Work = Work + Allocation[i]，Finish[i] = true，返回步骤2
  4. 如果所有进程的 Finish[i] 都为 true，则系统处于安全状态
